This guide explains the whole software in simple English.
You do not need to be a programmer to understand it.

What is Figma?
-------------------
Figma helps teams write exam books and MCQ question banks faster.

In normal Word software, people spend many hours fixing:
  - alignment
  - page size
  - headers and footers
  - question numbering
  - print layout

Figma does that layout work for you.
You mainly type the questions. The software handles the look and print setup.


================================================================================
PART 1 — HOW TO OPEN AND START
================================================================================

1. Open the project folder.
2. Run the app (dev server is usually already running).
3. You will see the Login screen first.
4. Click "Sign in to workspace" (demo login works).
5. After login, you enter the main software.

User name shown in the app: Karthikeyan


================================================================================
PART 2 — MAIN WORKFLOW (4 STEPS)
================================================================================

The software follows 4 simple steps:

  Step 1 → Content Ingestion & Template Setup
           Type or paste questions. Choose a template.

  Step 2 → Automated Layout & Styling
           Software aligns text, options, fonts, and spacing.

  Step 3 → Quality Control & Preview
           Check numbering, headers, footers, and layout errors.

  Step 4 → Multi-Size Export & Print
           Export as A4, B5, or 8×8 print-ready files.

----------------------------------------
5) QUICK EDITOR (MOST IMPORTANT MODULE)
   File: src/pages/Editor.tsx
   Helper: src/lib/editorEngine.ts
----------------------------------------

Purpose:
  Type questions quickly. See print preview live.

The editor has 3 columns:

  LEFT  → Blocks / Options / Marks library
  MIDDLE → Typing area
  RIGHT → Live print preview


A) Top toolbar features
-----------------------
  - Book title (current book name)
  - Paper size switch: A4 | B5 | 8×8
      * Changing size updates the live preview shape
  - Column switch: 1-col | 2-col
      * Changes how options are shown
  - Undo / Redo
  - Auto-number
      * Fixes question numbers in order (101, 102, 103...)
  - Paste import
      * Paste text from Word/Excel and clean it
  - Balanced / Overflow mode
      * Balanced = auto fix page overflow
      * Overflow mode = show warning if content is too long
  - Shortcuts button
  - Auto-save status
  - QC button
  - Export button


B) Left library — Blocks tab
----------------------------
Insert ready question shapes with one click:

  - MCQ — A B C D      (Ctrl+4)
  - MCQ — A–E          (Ctrl+5)
  - True / False       (Ctrl+T)
  - Fill blank         (Ctrl+F)
  - Match list         (Ctrl+M)
  - Assertion-Reason

Each insert adds the next correct question number.


C) Left library — Options tab
-----------------------------
Change how options look:

  - A, B, C, D format
  - A, B, C, D, E format
  - i, ii, iii, iv format
  - 1, 2, 3, 4 format
  - ABCD inline (all options on one line)
  - Toggle 1-column / 2-column layout


D) Left library — Marks tab
---------------------------
Insert special markers:

  - ★ Key point
  - ✓ Answer
  - ◆ Definition
  - → Direction
  - • Subpoint
  - — Em dash


E) Middle typing area
--------------------
  - Type questions in plain text
  - Format example:

      101. Question text here?
      (A) Option one
      (B) Option two
      (C) Option three
      (D) Option four [✓ D]

  - Status bar shows:
      * Format version
      * Column mode
      * Current paper size
      * Character count


F) Right live preview
---------------------
  - Shows pages like real paper
  - Changes when you type
  - Changes when you switch A4 / B5 / 8×8
  - Mini paper shapes at top to compare sizes
  - Shows headers and footers
  - Shows overflow warning if content does not fit
  - Click overflow warning to rebalance


G) Editor brain (engine)
   File: src/lib/editorEngine.ts
------------------------------------------------
This file does the smart work behind the editor:

  - parseQuestions()
      Reads your text and finds each question + options

  - paginateQuestions()
      Splits questions into pages based on paper size

  - PAPER_META
      Stores size rules for A4, B5, and 8×8
      (width, height, questions per page, font size)

  - templatesFor()
      Builds ready question templates

  - renumberContent()
      Fixes numbering order

  - applyOptionFormat()
      Changes option letter style

  - structurePaste()
      Cleans pasted Word/Excel text

  - nextQuestionNumber()
      Finds the next number to use

PART 7 — SIMPLE DAY-TO-DAY USAGE
================================================================================

Typical day for a typist:

  1. Sign in
  2. Open Dashboard
  3. Click "Start typing questions" or open Quick Editor
  4. Choose paper size (A4 / B5 / 8×8)
  5. Click a Block (example: MCQ A B C D)
  6. Type the question text and options
  7. Watch Live Preview on the right
  8. Use Auto-number if numbers look wrong
  9. Open QC Review and fix any flags
 10. Press Ctrl+P and export print files


Typical day for a layout lead:

  1. Check Dashboard QC flags
  2. Open Books and review chapter status
  3. Run QC Review and use one-click fixes
  4. Confirm live preview on all 3 sizes
  5. Export press-ready package


================================================================================
PART 8 — PAPER SIZES EXPLAINED SIMPLY
================================================================================

  A4
    Common exam book size.
    Tall rectangle.
    Fits more content per page.

  B5
    Slightly smaller academic size.
    Good for compact books.

  8×8
    Square workbook size.
    Less vertical space.
    Content may need more pages.


Important:
  You type once.
  Figma can scale the same content to all three sizes.
