PART 1 — PROJECT OVERVIEW
--------------------------------------------------------------------------------

Traditional tools (e.g. Microsoft Word) force typists and layout staff into
manual alignment, fragile formatting, and repeated fixes whenever text
overflows or page size changes.

Figma is a browser-based publishing workspace built for educational
content: MCQ banks, scanned / pasted question papers, and structured course
manuals. Users type or scan content; the suite automates layout, headers,
footers, page geometry, formula rendering, and print-ready export for three
fixed sizes only: A4, B5, and 8×8.

How teams work today (current product)
  1. Sign in
  2. Open Documents → New book (name + page size)
  3. Edit in a Word-style full-page editor (ribbon + paper canvas)
  4. Use AI Scan / Auto Align / Compile as needed
  5. Print / PDF export

Key business benefits
  • Time savings — less hand alignment, renumbering, and size rework
  • Print readiness — A4, B5, and 8×8 from one source document
  • Consistency — shared header/footer styles, topic numbering, MCQ structure
  • Content focus — typists work on text; layout tools handle presentation


--------------------------------------------------------------------------------
PART 2 — END-TO-END WORKFLOW (CURRENT)
--------------------------------------------------------------------------------

  [ 1. Create book & ingest content ]
                 ↓
  [ 2. Edit, structure & auto-layout ]
                 ↓
  [ 3. Preview, align & compile ]
                 ↓
  [ 4. Multi-size print / PDF export ]


1) Create book & ingest content
  • New book wizard: title + paper size (A4 / B5 / 8×8)
  • Documents library: open recent books (saved in browser storage)
  • Content entry in the editor:
      – Type body text, topics, MCQs, formulas
      – Paste a question paper (text)
      – AI Scan Image — OCR photo/scan → questions, choices, answers
      – Insert image for figures/diagrams
  • Secure sign-in gate before the workspace

2) Edit, structure & auto-layout
  • Word-like ribbon: Home · Insert · Layout · Fonts · AI & Export
  • Quick bar (always visible): Undo/Redo, Topic, 1.1, MCQ, Math, + Page,
    size switch, font picker, large AI Scan, Auto Align, Compile Book
  • Course structure: Topic N + subheadings 1.1 / 1.2 / 1.3 (topic tree)
  • MCQ tools: blank MCQ, auto-generated MCQs with answers, answer-key page
  • Math: KaTeX formulas ($…$ / $$…$$) with dedicated math fonts
  • Fonts: English, Tamil, Math presets + import/export of custom fonts & packs
  • Headers & footers: Classic / Academic / Modern / Minimal; editable text;
    page numbers; different first page
  • Auto Align — cleans page and structures detected MCQs
  • Compile Book — whole-book clean-up + image placement tips

3) Preview, align & compile
  • Live paper canvas scaled to the selected print size
  • Page list for multi-page books (add / navigate / delete pages)
  • Placement tips after compile or image insert
  • Undo / Redo (Ctrl+Z / Ctrl+Y) across document changes

4) Multi-size export & print
  • Switch A4 ↔ B5 ↔ 8×8 in the editor; canvas and export follow the size
  • Headers, footers, and page numbers recalculate with the document
  • Print / PDF — opens a print-ready view (browser Print → Save as PDF)
  • Shortcut: Ctrl+P / Ctrl+E from the editor

PART 3 — PROJECT OBJECTIVES
--------------------------------------------------------------------------------

  • Reduce manual document formatting for exam and course books
  • Automate layout for topics, MCQs, headers/footers, and page geometry
  • Cut production time from typing to print-ready PDF
  • Keep styling consistent across a book and across size variants
  • Support A4, B5, and 8×8 from a single source
  • Speed up paper intake via paste + AI image OCR for questions/answers
